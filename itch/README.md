# itch.io page material

- `cover-630x500.png`: cover image at itch.io's recommended size; `cover.png` is the same at twice the size.
- `screenshot-1-menu.png` to `screenshot-5-forest.png`: page screenshots, 1280×720.
- `description.md`: the page description. Paste it into the description box (itch.io accepts Markdown if the editor is switched to it; otherwise paste and tidy the headings).
- Short text for the "tagline" field: **Plant a field. Bet a century.**

All images are frames of the running game. The publish workflow does not upload them: set the
cover and screenshots by hand on the itch.io edit page.
